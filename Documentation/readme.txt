Plugin Description: Add 4 boxes to upload file attachments allowed 5.



This plugin its function is to add 4 boxes to upload files and thus avoid the task of uploading one by one and thus upload 5 files allowed!

To insert in the message we click on Update Attachment and appear below in order to insert the message!

Installation:
Replace the file newthread.php for the attachment.
Then go to admin panel / Configuration / Plugins and activate the plugin MultiAttachments
